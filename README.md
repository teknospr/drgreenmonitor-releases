# Dr Green Monitor — desktop app

Installers for the Dr Green Monitor desktop app (Windows, macOS, Linux). No source code is kept here.

Download the latest version from [Releases](https://github.com/teknospr/drgreenmonitor-releases/releases/latest), open the app and paste the desktop token from the Dr Green Monitor website (Desktops → Add desktop). Installed apps update themselves from here with the Update button.
