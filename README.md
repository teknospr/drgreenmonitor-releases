# Solarman Checker — desktop app

Installers for the Solarman Checker desktop app (Windows, macOS, Linux). No source code is kept here.

Download the latest version from [Releases](https://github.com/teknospr/solarman-checker-releases/releases/latest), open the app and paste the desktop token from the Solarman Checker website (Desktops → Add desktop). Installed apps update themselves from here with the Update button.
